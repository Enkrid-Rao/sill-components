# sill.media

Windows 当前正在播放的内容，加上传输键和系统音量。

## 显示什么

- `NOW PLAYING` 标题。
- 标题、艺术家 / 专辑（没有艺术家时退回应用名）。
- 播放中的三格小均衡器；暂停时不显示。
- 进度条、当前时间 / 总时长。
- 上一首、播放 / 暂停、下一首。
- 音量图标、音量滑杆、静音开关；拖动时显示百分比。

没有封面图。封面位置是一个由主题色驱动的占位块，不读 SMTC 的缩略图——那需要额外的
Windows API 调用与缓存，v1 不做。

## 数据与权限

| 数据 | provider | 权限 |
|---|---|---|
| 当前会话 | `media.nowPlaying` | `data.media` |
| 播放控制 | `media.playpause` / `next` / `prev` / `mute` / `volume` | `data.media` |

`data.media` 同时允许读和写；安装时要明确提示「可以控制你的媒体播放」。

## 尺寸与跨列

- 建议尺寸：384 × 256。
- 跨列：1。
- 三列时内容宽约 253px，播放键仍然保持 28px 的点击目标；185px 下会切换到紧凑排布。

## 交互

- 播放 / 暂停是乐观的：点击后立刻切换图标，最多等 2.6 秒让 SMTC 追上；采集端本身有约 2 秒延迟。
- 音量在拖动时不发命令，松手后 80ms 提交；键盘微调走 320ms 防抖。
- 音量命令失败时回退到宿主快照的值。
- 没有会话时只显示空态，不隐藏整张卡。

## 空态与错误

- 没有 SMTC 会话：显示「Nothing playing」。
- 会话停止 / 关闭：按空态处理。
- 命令失败：图标回到宿主状态，不弹错。
- 宿主音量还没读上来（`volume < 0`）：滑杆先按 0 处理，等下一次快照追上。

## 实现状态

**内置 React 实现，随 Sill 0.5.4 发布。** 源码：
[`MediaWidget.tsx`](https://github.com/Enkrid-Rao/sill/blob/v0.5.4/apps/desktop/src/renderer/src/components/widgets/MediaWidget.tsx)。

`installable: false`。

## 迁移到 `.sill`

模板 v1 不执行 JS、不接收命令，做不了播放控制和乐观状态；media 仍是 React 内置组件。
需要命令/状态的组件走后续的受限脚本路线，不混进模板。

## 验收

- 无会话、暂停、播放、停止四种状态都正确。
- 点击播放后图标立即变化，2.6 秒内不被旧快照打回。
- 键盘可以到达三个传输键和音量滑杆；每个图标按钮都有 `aria-label`。
- 音量拖到 0 与 100 时不会越界；静音时显示 `—`。
- 中文下标题与艺术家不重叠，超长标题截断。
