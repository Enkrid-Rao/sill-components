# sill.todo

本地待办。勾选、编辑、删除都不应该让周围的卡片跳一下。

## 显示什么

- `TODO` 标题 + Open / Closed / All 三段过滤器。
- 未完成 / 已完成任务列表；已完成项有勾选标记和删除线。
- 底部输入框：输入后 Enter 添加。
- 删除后的 5 秒撤销条。

## 数据与权限

| 数据 | provider | 权限 |
|---|---|---|
| 待办列表 | `todo.list` | `data.todo` |
| 添加 / 勾选 / 编辑 / 删除 | `todo.add` / `toggle` / `update` / `remove` | `data.todo` |

数据写在宿主的 `todo.json`，不是组件存储。`storage` 权限对这张卡不是必需的。

## 尺寸与跨列

- 建议尺寸：384 × 300。
- 跨列：三列时默认整行（3），两列时 1，单列时 1。用户可以在布局编辑里改。
- 卡片会吃掉剩余高度（`card--grow`），列表超出时由面板滚动。

## 交互

- **过滤**：Open 只显示未完成，Closed 只显示已完成，All 全显示；过滤器本身不写盘。
- **勾选**：先改本地镜像，再调 `todo.toggle`；在 Open 下勾上时，勾选动画留 360ms 再按过滤器收合。
- **行内编辑**：双击或点编辑进入；Enter 保存，Esc 取消，失焦保存。
- **删除**：先做 280ms 的横向淡出 + 行高收合，再调 `todo.remove`；成功后显示 5 秒撤销，
  恢复原 id、完成状态和位置。
- **输入框**：聚焦时通过 `window.sill.setTyping(true)` 告诉宿主「别把 Esc 当成收面板」；
  失焦后恢复。
- 所有动画只改 `transform` / `opacity` / 行高，不做 `translateY` 的整体位移。

## 空态与错误

- 列表为空：显示「Nothing here」和一条引导文案。
- 过滤后为空：保留过滤器与输入框，只把列表区换成空态。
- 命令失败：列表回到宿主快照；删除失败时把行从收合态恢复，不留下半张卡。
- 待办文件损坏：宿主按空列表处理，不阻塞面板。

## 实现状态

**内置 React 实现，随 Sill 0.5.4 发布。** 源码：
[`TodoWidget.tsx`](https://github.com/Enkrid-Rao/sill/blob/v0.5.4/apps/desktop/src/renderer/src/components/widgets/TodoWidget.tsx)。

`installable: false`。它是 React 内置组件；模板 v1 做不到表单/状态/动画。

## 迁移到 `.sill`

模板 v1 不执行 JS、没有表单和动画，做不了添加/勾选/编辑/撤销；todo 仍是 React 内置组件。
需要交互的组件走后续的受限脚本路线，不混进模板。

## 验收

- 勾选后行在原位停留至少 360ms，再按过滤器收合，不出现整列跳动。
- 删除后 5 秒内撤销能恢复原位置；5 秒后撤销条消失。
- Enter 添加、Esc 取消编辑、失焦保存三条路径都正确。
- 输入中文时按 Enter 不会在 IME 组合态误提交。
- 三列整行与单列窄卡两种布局都不横向溢出。
- 卸载 / 重开面板后待办仍在（数据在 `todo.json`）。
