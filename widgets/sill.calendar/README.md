# Calendar · 日历

月历卡：月份 + 年份、周标题、固定六周的日期网格，今天用强调色圆点标出。
可以翻月，翻走以后出现「今天」胶囊，一键回到本月。

- provider：`time.now`
- 权限：`data.time`
- 默认尺寸：384 × 232，跨 1 列
- 无卡片标题；格子高度和字号随卡片宽度缩放

## 行为

- 中文周一开头、英文周日开头；月份名英文用 `Intl`（November），中文用 `11月`；
- **固定 42 格（六周）**：上月尾 / 下月头用淡色数字补齐，翻月时卡片高度不跳；
- 上 / 下月按钮：改的是本地视图，不写任何存储；翻走后右上角出现「今天」胶囊，
  点一下回到本月并恢复高亮；
- 跨年翻月、跨月跨天都正确；页面重开回到本月；
- 今天用 `--accent` 实心圆 + 淡光晕，数字用 `--accent-ink`，不靠颜色单独表意：
  同时带 `aria-label`（`2026年11月 · 11月20日 周五`）；
- 数据没到时只显示占位，不抛错。

## 布局

- 窄卡（< 520px 内容宽）：月份 + 年份一行，导航在右；再往下是周标题和网格；
- 最窄（< 240px）：隐藏年份，把宽度让给导航和「今天」；
- 宽卡（≥ 520px）：左边一列放月份、年份、今天的日期和导航，右边是日期网格；
  整块居中，网格最宽 420px，不会把格子拉成大方块；
- 185px 下不横向溢出，六行网格仍可读。

## 交互

- 上 / 下月、「今天」有 hover / active / `:focus-visible` 状态；
- 按钮是真实 `<button>`，带 i18n 的可访问名（上个月 / 下个月 / 今天）；
- 翻月有 160ms 的淡出淡入，`prefers-reduced-motion` 时关闭。

## 设计说明

月份用衬线斜体做视觉锚点，网格数字保持 sans + `tabular-nums`，翻月不抖。
日期格本身不可点（没有日程数据，不做假交互），所以没有给格子加 hover。
今天的高亮是圆点而不是整格填色，窄卡里也不会变成椭圆。

```powershell
sill pack ./sill.calendar -o sill.calendar-1.1.0.sill
```
