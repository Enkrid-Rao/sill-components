# sill.hero

日期、时钟和当前天气，放在侧边廊最上面的一张卡。视觉上它是整条廊子的标题，不是一张普通卡片。

## 显示什么

- 一行日期：`11月16日 周日` / `Sun, Nov 16`，按 `language` 本地化。
- 一行大号时间：`HH:mm`，24 小时制，每分钟更新。
- 天气区：WMO 天气图标、当前温度、天气描述、城市名、最高 / 最低温。
- 天气图标按 18:00–06:00 切成夜间图标；`code < 0` 表示还没有天气数据，显示月亮 + 云。

## 数据与权限

| 数据 | provider | 权限 | 说明 |
|---|---|---|---|
| 时间 | `time.now` | `data.time` | 宿主每秒推进；组件只读 |
| 天气 | `weather.current` | `data.weather` | 15 分钟刷新，或切换城市时立即刷新 |

权限只有这两个。它不读系统指标、不读待办、不联网。

## 尺寸与跨列

- 建议尺寸：384 × 180。
- 跨列：**始终整行**。两列 / 三列时 `grid-column: 1 / -1`，由 CSS 的 `.card--hero` 保证；
  单列时自然占满。
- 最窄可用宽度：约 185px（三列单跨的极端情况不会发生在它身上，因为它总是整行）。

## 交互

这张卡没有点击行为。天气失败时不会弹窗，也不阻塞时钟。

## 空态与错误

- 还没拿到天气：温度 `--°`，描述显示「定位中」/「加载中」。
- 天气请求失败：保留上一次成功数据；`stale` 为真时仍然显示旧值。
- 完全无数据：图标退回月亮 + 云，城市名显示「定位中」。
- 城市名优先用 `cityId` 查本地化表，查不到再用 provider 的 `cityName`。

## 实现状态

**内置 React 实现，随 Sill 0.5.4 发布。** 源码：
[`HeroWidget.tsx`](https://github.com/Enkrid-Rao/sill/blob/v0.5.4/apps/desktop/src/renderer/src/widgets/HeroWidget.tsx)。

它不是 `.sill` 包，`installable: false`。

## 迁移到 `.sill`

模板 v1 只有文本绑定，没有条件图片 / 资源白名单；hero 仍是 React 内置组件。
等模板支持 `data-sill-if` 和图片资源后再迁。

## 验收

- `zh` / `en` 下日期、城市名、天气描述都切换，不残留旧语言。
- 320 面板宽（单列）和 1180 面板宽（整行）都不溢出。
- 断网后仍然显示上一次天气，时钟继续走。
- 06:00 / 18:00 前后图标切换正确。
