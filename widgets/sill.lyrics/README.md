# Lyrics · 歌词

显示当前播放歌曲的同步歌词。数据来自 `media.nowPlaying`，歌词来自 [LRCLIB](https://lrclib.net)
（免费、开放 CORS），不需要 API key。

## 安装

- 应用内：设置 → 组件 → 从 URL 安装，粘贴
  `https://raw.githubusercontent.com/Enkrid-Rao/sill-components/main/registry/packages/sill.lyrics-1.1.0.sill`
- 或从组件目录安装（`sill.lyrics`）
- 源码在 `widgets/sill.lyrics/`，也可以直接放进 `skins/` 开发

## 行为

- 歌曲 / 歌手变化时向 LRCLIB 搜索一次；优先选时长差 ≤ 6 秒的同步歌词，其次按时长差排序，
  没有再退回无时间轴歌词；
- 播放中每 200ms 推进当前行与「当前行 → 下一行」的进度线；暂停时停住，切歌自动重载；
- 查询结果在内存里缓存 10 分钟（同一首歌重复出现不再请求），切歌会中止上一个请求；
- 同步歌词按 `[mm:ss.xx]` 解析，支持一行多时间戳；相邻、同词、时间差 < 0.35s 的重复行会合并；
- 没有网络 / 超时（9 秒）会进入「歌词暂时取不到」，可以点「重新搜索」；查不到歌词显示
  「没有找到歌词」，纯音乐显示「纯音乐」；
- 设置 → 组件 → 歌词 → 歌词偏移：`-10 … +10` 秒，用于校正现场 / 蓝牙延迟；非 0 时
  标题右侧会出现 `+1.5s` 的小胶囊，提醒当前不是原始时间轴。

## 状态

| 状态 | 表现 |
|---|---|
| `idle` | 「没有在播放」+ 一句提示 |
| `loading` | 两条骨架线 + 「搜索中」徽标 |
| `synced` | 当前行 + 下一行 + 行进度线 + 「同步」徽标（带呼吸圆点） |
| `plain` | 最多四行无时间轴歌词，第一行加重 |
| `empty` | 「没有找到歌词」+ 提示 + 重新搜索 |
| `error` | 「歌词暂时取不到」+ 提示 + 重新搜索 |
| `instrumental` | 「纯音乐」+ 提示 |

状态文案全部走 `widget.json` 的 `strings`，中英各一套，不在 JS 里硬编码。

## 代码结构

- 请求：`AbortController` + 9 秒超时 + 自增 `requestSeq`，旧请求回来不会覆盖新歌；
- 推进：只在「有同步歌词且正在播放」时开 `setInterval`，暂停 / 切歌 / 卸载时清掉；
- `sill.onDispose` 里中止请求、清计时器，热重载不会留下后台轮询。

## 隐私与限制

- 会把**歌名、歌手、专辑、时长**发给 `lrclib.net`；不接受的话不要安装。
- 只按歌名 / 歌手匹配，不读本地文件，也不读歌曲旁边 `.lrc`；
- 依赖 LRCLIB 的曲库，冷门歌可能没有歌词；
- 时间轴精度约 200ms，适合逐行歌词，不适合作逐字卡拉 OK。

## 布局

- 窄卡：当前行 15–19px、下一行 11.5–13px，进度线 2px；
- 宽卡（≥ 520px）：整块限宽 720px 居中，避免一句话被拉成一条横线；
- 卡片固定最小高度 150px，切歌 / 加载 / 空态之间不会上下跳。

```powershell
sill pack ./sill.lyrics -o sill.lyrics-1.1.0.sill
```
