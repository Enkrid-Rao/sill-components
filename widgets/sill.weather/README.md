# Weather · 天气

当前天气卡：城市、天气图标、温度、天气描述和当天最高 / 最低温。图标按 WMO code 分
晴 / 多云 / 阴 / 雾 / 毛毛雨 / 雨 / 雪 / 雷雨，晴天与多云在夜间换成月亮。

- provider：`weather.current`
- 权限：`data.weather`
- 默认尺寸：384 × 150，跨 1 列
- 无卡片标题；图标和温度随卡片宽度缩放
- 天气失败时沿用宿主上一次成功的数据（`stale`），并在右下角标出更新时间

## 状态

| 状态 | 触发 | 表现 |
|---|---|---|
| `loading` | 还没拿到数据 | 图标与温度变淡，显示「正在获取天气…」，底部先隐藏 |
| `ready` | 有温度、无错误 | 正常显示 |
| `stale` | 本次请求失败但保留了旧数据 | 图标变淡，右下角显示「更新于 HH:MM」+ 强调色圆点 |
| `error` | 没有可用数据 | 图标变淡，温度 `--`，显示「天气暂不可用」 |
| 无高低温 | `high/low` 为 `null` | 不显示底部一行，不留下孤立的横线 |

以前 `null` 会被 `Number(null)` 变成 `0`，于是没数据时显示 `0° / 高 0° 低 0°`；
现在所有数字都先做 `typeof === 'number' && Number.isFinite` 判断。

## 设置

| key | 类型 | 默认 | 说明 |
|---|---|---|---|
| `unit` | select | `c` | 显示 °C 或 °F；高低温一起换算 |

## 布局

- 窄卡：眉标 + 城市一行，图标 + 温度 + 描述一行，底部横线内放高低温与缓存时间；
- 宽卡（≥ 520px）：天气在左、高低温与更新时间在右，不做横向拉伸；
- 185px 下温度、描述、高低温都不横向溢出；无数据时也没有多余空白行。

## 设计说明

图标是 32×32 的双色线稿：日 / 月用 `--accent`，云用 `--ink-soft`，雷电压在 `--accent-2` 上。
所有颜色来自主题变量，切换 Ember / Aurora 时图标跟着变色。温度与 Clock 卡同为衬线斜体，
`tabular-nums` 保证 `9° → 10°` 不跳宽。

```powershell
sill pack ./sill.weather -o sill.weather-1.1.0.sill
```
