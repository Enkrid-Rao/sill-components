# Testing & acceptance

组件不是“能显示”就算完成。下面这份清单是发布前的最低验收。

## 1. 自动校验

计划中的 `sill validate` 应覆盖：

- [ ] `widget.json` 可解析、`schema=1`、必填字段齐全
- [ ] `id` 格式与唯一性
- [ ] `version` / `runtime` 是合法 semver / range
- [ ] `type` 与 `ui` 扩展名匹配
- [ ] 路径不逃出包根
- [ ] 未声明的权限没有被使用
- [ ] `settings[].key` 唯一、默认值类型正确
- [ ] IR 节点/属性白名单通过
- [ ] 绑定表达式只使用允许的语法
- [ ] 单文件/总包大小在上限内
- [ ] 没有 `eval` / `new Function` / 远程脚本（script）

## 2. 视觉矩阵

在以下宽度各截一张图，检查无横向溢出、无文字重叠、无裁切：

| 面板 | 宽度 | 列数 |
|---|---|---|
| 窄侧廊 | 320 | 1 |
| 默认侧廊 | 384 | 1 |
| 板式 | 660 | 2 |
| 宽屏 | 920 | 3 |
| 最宽 | 1180 | 3 |

语言：`zh` / `en` 各一遍。中文检查：

- [ ] 最小字号 ≥ 10.5px
- [ ] 字距不过度拉伸（caption 不要用 0.17em）
- [ ] 浅色说明文字对比度足够
- [ ] 中英混排没有基线跳动

主题：至少 `Clear`、`Lagoon`、`Dusk` 三套；检查强调色、玻璃背景、深浅对比。

## 3. 交互

- [ ] 鼠标悬停、点击、键盘 Tab / Enter / Esc 都能完成主路径
- [ ] 焦点环可见；图标按钮有 `aria-label`
- [ ] 输入框支持 Esc 取消 / Enter 提交（如适用）
- [ ] 删除/清空有撤销或确认（如适用）
- [ ] 组件不抢焦点、不注册全局快捷键
- [ ] 面板收起再唤出后状态正确
- [ ] 切换语言后文案即时更新，不残留旧语言

## 4. 数据与错误

- [ ] 数据未就绪时显示占位，不抛错
- [ ] 数据源失败时保留上一次值或显示错误态
- [ ] 数据更新不会造成整卡闪烁/布局跳动
- [ ] 卸载后没有定时器/监听器泄漏
- [ ] 脚本崩溃只影响当前卡片
- [ ] 网络失败/超时不会卡住面板

## 5. 性能

- [ ] `mount` < 50 ms
- [ ] 常规 `update` < 8 ms
- [ ] 没有 >10 Hz 的自建轮询
- [ ] 动画只改 `transform` / `opacity`
- [ ] 连续开合面板 20 次，内存无明显增长
- [ ] 1180 宽 + 3 列下不横向滚动

## 6. 减少动态效果

- [ ] `prefers-reduced-motion: reduce` 下关闭非必要动画
- [ ] 状态仍然可读（不能只靠动画表达完成/错误）

## 7. 安全

- [ ] 只申请实际使用的最小权限
- [ ] 没有硬编码凭证/token
- [ ] 网络域名在 manifest 白名单内
- [ ] 不读取包外文件
- [ ] 不使用 `eval` / 动态脚本
- [ ] 存储键不写 `__proto__` / `constructor`
- [ ] 安装包解压后没有意外文件

## 8. 手工收益检查

最后问三个问题：

1. 这张卡在 384 宽下，用户能不能在 3 秒内读出最重要的信息？
2. 它是否比 Sill 自带组件更值得占用一块玻璃？
3. 删掉它，面板会不会更好？

如果第 3 个问题的答案是“会”，组件还不该发布。
