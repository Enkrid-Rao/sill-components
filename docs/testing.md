# Testing & acceptance

组件不是「能显示」就算完成。下面这份清单是发布前的最低验收。

## 1. 自动校验

先跑：

```bash
python scripts/validate.py
```

它会检查：

- [x] `widget.json` 可解析、`schema=1`、必填字段齐全
- [x] `id` 至少两段、格式合法
- [x] `version` / `runtime` / `engine` 是合法 semver / range
- [x] `type=template`；`ui` 指向 `.html`
- [x] `ui` / `style.css` 存在，路径不逃出包根
- [x] `permissions` 覆盖 `data[].source`
- [x] `data[].id` 不重复；provider 字段存在
- [x] HTML 只用白名单标签 / 属性
- [x] 没有 `<script>`、`on*`、`style` 属性、`href` / `src`
- [x] CSS 没有 `@import`、`url()`、`expression`
- [x] 没有 `ui/*.js`
- [x] 包大小 / 文件数在上限内
- [x] `registry/catalog.json` 的 id 唯一、`docs` 存在

CI 会在每次 push / PR 跑同一份脚本。它不替代手工视觉验收。

## 2. 玻璃与 atmosphere

这是模板方案的核心，必须单独看：

- [ ] 卡片背景就是 `.card` 的玻璃，不是模板自己铺的；
- [ ] 卡片背后能看到当前 atmosphere（Lagoon 等主题）；
- [ ] 模板没有在 `:host` / 根节点写背景色；
- [ ] 卡片圆角、边框、内高光与相邻内置卡一致；
- [ ] 主题切换时文字/强调色跟着变，不残留旧色。

至少截三张图：

| 场景 | 面板宽 | 主题 |
|---|---|---|
| 默认 | 384 | Clear |
| 氛围 | 384 | Lagoon |
| 窄宽 | 320 | Clear |

## 3. 视觉矩阵

按**卡片内容宽**截图，不是按面板宽：

| 面板宽 | 列数 | 单跨内容宽 |
|---|---|---|
| 320 | 1 | 254 |
| 384 | 1 | 318 |
| 485 | 2 | 190 |
| 660 | 2 | 273 |
| 714 | 3 | 185 |
| 920 | 3 | 253 |
| 1180 | 3 | 340 / 1110 |

- [ ] 185px 下没有横向溢出、文字重叠、裁切
- [ ] 1110px 下没有把内容拉成一条细线
- [ ] 单跨与跨列都正常
- [ ] 高度由内容决定

语言 `zh` / `en` 各一遍：

- [ ] 最小字号 ≥ 10.5px
- [ ] 中英混排没有基线跳动
- [ ] 长标题不撑破卡片

DPI：Windows 100% / 125% / 150% 各看一次。

## 4. 数据与错误

- [ ] 数据未就绪时显示 `—`，不抛错
- [ ] provider 字段缺失时显示 `—`
- [ ] 数据更新只改绑定节点，不整卡闪烁
- [ ] 模板 HTML/CSS 非法时显示错误占位，其他卡正常
- [ ] 卸载/重开面板后没有残留 DOM 或监听器

### 模板指令

- [ ] `data-sill-text` 缺失值显示 `—`
- [ ] `data-sill-i18n` 中 / 英切换正确，找不到时回退 key
- [ ] `data-sill-if` 真 / 假 / `!` 三种情况
- [ ] `data-sill-repeat` 空数组移除模板行
- [ ] repeat 内 `item.*` 正确，嵌套不超过 8 层
- [ ] 数据更新后列表行数正确

## 5. 性能

- [ ] 首次渲染 < 16 ms
- [ ] 数据更新 < 4 ms
- [ ] 模板 DOM 节点 < 500
- [ ] 没有自建轮询（模板没有 JS）
- [ ] 1180 宽 + 3 列下不横向滚动

## 6. 安全

- [ ] 只申请实际使用的数据权限
- [ ] 没有 `<script>` / `on*` / `style` 属性 / `href` / `src`
- [ ] CSS 没有 `@import` / `url()`
- [ ] 没有 `ui/*.js`
- [ ] 不读取包外文件
- [ ] 安装包解压后没有意外文件

## 7. 可访问性

- [ ] 纯展示内容仍有足够对比度
- [ ] 中文最小字号 10.5px
- [ ] 不用颜色作为唯一状态表达
- [ ] 模板不抢焦点、不注册全局快捷键

## 8. 安装 / 卸载

- [ ] `.sill` 根目录只有 `widget.json`、`ui/index.html`、`ui/style.css`
- [ ] 压缩包 ≤ 10 MB，单文件 ≤ 512 KB
- [ ] 安装前显示 id / 版本 / 作者 / 权限，取消不写入
- [ ] 安装后设置里出现组件，面板里出现卡片
- [ ] 重复安装同 id 被拒绝
- [ ] 卸载后卡片消失，包目录被删除
- [ ] 坏包（额外文件 / `../` / `<script>` / CSS `url()`）被拒绝，不留下半个包
- [ ] 安装失败有可读错误

## 9. 手工收益检查

最后问三个问题：

1. 这张卡在 318px（默认 rail）下，用户能不能在 3 秒内读出最重要的信息？
2. 它是否比 Sill 自带组件更值得占用一块玻璃？
3. 删掉它，面板会不会更好？

如果第 3 个问题的答案是「会」，组件还不该发布。
