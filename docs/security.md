# Security model

组件的默认假设：**代码不可信**。它由第三方编写，可能出错、可能恶意。

## 1. 资产

要保护的东西：

- 用户的文件系统、剪贴板、浏览器会话、其他应用数据。
- Sill 的设置、待办、天气地区、布局。
- 面板的窗口句柄、置顶层、热键。
- 其他组件的数据与存储。

组件不应该获得任何一项的默认访问权。

## 2. 边界

```
┌──────────────────────────────┐
│ 主进程（Node / Electron）      │  ← 只有这里能碰 fs / 窗口 / 网络 / 子进程
│  settings / todo / weather    │
└──────────────┬───────────────┘
               │ 受控 IPC
┌──────────────▼───────────────┐
│ Renderer（React 宿主）         │
│  WidgetShell / IR / 内置组件   │
└──────────────┬───────────────┘
               │ postMessage（结构化）
┌──────────────▼───────────────┐
│ sandbox iframe（脚本组件）      │  ← 无 same-origin、无 Node、无直接网络
└──────────────────────────────┘
```

- 声明式 IR 不执行代码；只做受限求值与节点渲染。
- 脚本组件永远在 iframe 内；宿主不把 `window` / `document` 传进去。
- 组件不能直接调用主进程 IPC；所有能力走 context 方法。

## 3. 权限

| 权限 | 风险 | 控制 |
|---|---|---|
| `data.time` | 低 | 只读本地时间 |
| `data.system` | 中 | 只读聚合指标，不暴露进程路径/命令行 |
| `data.media` | 中 | 只读当前会话标题/艺术家/进度，不暴露其他应用数据 |
| `data.weather` | 低 | 只读天气快照；不暴露精确坐标（除非用户选择） |
| `data.todo` | 中 | 可读写待办；安装时明确提示 |
| `data.files` | 高 | 只能读用户通过系统选择器明确选中的文件 |
| `storage` | 低 | 按组件隔离，有配额 |
| `network` | 高 | 域名白名单、HTTPS、限速、配额；默认拒绝私有 IP |
| `commands` | 中 | 只允许固定命令；`openUrl` 只允许 http/https |
| `settings` | 低 | 只读写组件自己的设置 |

- 权限在安装时展示，不能静默升级。
- 组件升级新增权限时必须重新征得用户同意。
- 未声明的调用直接拒绝并记录审计日志（计划中）。

## 4. 路径与包

- 拒绝 `..`、绝对路径、Windows 盘符、UNC、符号链接逃逸。
- 解压 `.sill` 时限制：总解压 ≤ 50 MB、文件数 ≤ 500、单文件 ≤ 10 MB、压缩比异常拒绝（zip bomb）。
- 只允许 manifest 声明的资源；其他文件不进入安装目录。
- 安装使用临时目录 + 原子 rename；失败不留下半个包。
- 组件目录名由 `id@version` 生成，不信任压缩包内目录名。

## 5. 脚本沙箱

- iframe `sandbox="allow-scripts"`，**不加** `allow-same-origin`。
- 不加载远程脚本；包内脚本通过 nonce 注入。
- 禁止 `eval` / `new Function` / `document.write`（CSP + 运行时检查）。
- 禁止 `window.open`、`top.location`、`parent.document`。
- 超时：`mount` 5s，单次 `update` 100ms，消息 5s；超时销毁 iframe。
- 内存：单组件 64 MB 上限（计划中）；超过提示并停止。
- 崩溃隔离：一个组件崩溃不影响其他卡片；错误占位可手动重载。

## 6. 网络

- 只通过 `ctx.fetch`；域名白名单在 manifest 中声明。
- 默认仅 HTTPS；开发模式可显式允许 localhost。
- 拒绝私有地址段（10/8、172.16/12、192.168/16、127/8、169.254/16、IPv6 ULA/link-local）。
- 不允许自定义 `Cookie`、`Authorization` 跨域转发；不共享宿主 cookie。
- 超时 8s；每天 50 MB；按域名限速。
- 响应体不写入组件可访问的磁盘；只返回文本/JSON。

## 7. 存储

- 按组件 `id` 隔离；不能读其他组件。
- 1 MB / 100 keys 配额；超出拒绝并提示。
- 值必须 JSON；拒绝 `__proto__` / `constructor` 原型污染键。
- 组件卸载默认保留；用户可清除单个组件数据。
- 不存敏感凭证；文档明确告知存储是可读的本地文件。

## 8. 安装与更新

- 安装前展示：id、名称、版本、作者、权限、网络域名、大小。
- 签名：v1 不做代码签名；以哈希 + 用户确认为主，文档明确风险。
- 更新只允许同 `id`；新增权限需重新确认。
- 卸载删除组件目录与存储；不碰用户待办/设置。
- 组件不能修改 Sill 的全局设置或布局，除非有明确命令权限。

## 9. 审计与报告

计划中的审计日志记录：

- 安装/卸载/更新
- 权限拒绝
- 网络请求（域名、状态、大小，不含正文）
- 脚本超时/崩溃
- 存储配额拒绝

发现漏洞请通过仓库 issue 私下联系维护者，不要公开利用细节。
